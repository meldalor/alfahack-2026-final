## Топ-10 идей для `v12` (ранжировано по ROI)

### 1. Реал-тайм сигнал текущего часа в `causal_stream_features` (строго `< t`, 0 утечек)
- **Модуль:** `ag_features.py`
- **Проблема в `v11`:** часовая сенсорная панель для слота `10:00` запрещена до `11:00` (правило завершённых интервалов), но при событии в `10:18` прошлые события в этом же слоте (`10:02`, `10:07`, `10:14`, строго `< 10:18`) уже известны, и их **собственные не-таргетные признаки** (флаги, категории, типы вызовов/транзакций) абсолютно легальны.
- **Что добавить (100% универсально, без хардкода имён):**
  1. Для каждого бинарного флага и топ-категорий главной таблицы (исключая `target`, `id_col` и derived-колонки): строго причинная (`< t`) доля и счётчик за последние `15m`, `1h` и **«с начала текущего часа» (`floor(t, 1h) <= s < t`)** внутри группы (`district_id` / `user_id` / `merchant_id`) и по всей системе.
  2. Ускорение потока: `cnt_15m / (cnt_6h / 24 + 0.2)` и отношение текущего межсобытийного интервала к скользящей медиане группы.
- **Эффект:** закрывает главную зону крупных ошибок `> 5 min` (`storm_onset_15_59m` из `tools/analyze_task2_errors.py`) на Task 2 и мгновенно ловит начало фрод-атаки / аварии в первые 15 минут на Private LB.
- **Проверка безопасности:** обязательный dual-poison и online-stream аудит (`0 / N` изменений на прошлых строках).

### 2. Новые нейроархитектуры на чистом NumPy: **TabM (ICLR 2025) + FiLM + DCN-v2 + PLE**
- **Модуль:** `ag_models.py`, `solution.py`
- **Почему это главный рычаг:** `SwiGLU-ResNet` уже даёт >83% веса ансамбля, работает без новых пакетов (чистый NumPy/OpenBLAS) и на 8 CPU летает быстрее PyTorch.
- **Что добавить:**
  1. **TabM (BatchEnsemble rank-1 адаптеры):** одна общая матрица весов `W`, но `K = 8` параллельных адаптеров `h_k = (h_k * R_k) @ W * S_k` в одном forward/backward с усреднением голов на инференсе — качество ансамбля из 8 сетей по цене `~1.8x` одной сети.
  2. **FiLM-модуляция категорий (`gamma(cat) * h + beta(cat)`):** вместо простого аддитивного OHE в первом слое категории (район, тип инцидента, сегмент, клиент) мультипликативно масштабируют скрытое представление числовых признаков (`~15` строк NumPy).
  3. **DCN-v2 Cross-Layer (`x_{l+1} = x_0 * (x_l @ W_c + b_c) + x_l`):** третье ортогональное нейросемейство к `SwiGLU-ResNet` (явные полиномиальные взаимодействия 2–3 порядка).
  4. **PLE (Piecewise Linear Encoding — NeurIPS 2022):** 4–6 квантильных кусочно-линейных бинов на топ-15 числовых признаков (в отличие от Фурье-PLR не осциллирует на хвостах и даёт нейросети способность ловить резкие пороги, как у GBDT).

### 3. Умный отбор признаков для нейросетей (MRMR + дедупликация клонов)
- **Модуль:** `ag_models.py`, `solution.py`
- **Проблема в `v11`:** `fit_mlp` берёт `top_cols[:80]` строго по `LGBM gain`. Деревья забивают топ-80 десятками скоррелированных лагов одного сенсора (`|corr| > 0.98`), вытесняя гладкие/независимые фичи, которые нейросеть отлично складывает.
- **Что добавить:**
  - Гибридный рейтинг важности (`rank(LGBM_gain) + rank(CatBoost_imp / |Ridge_coef|)`).
  - Жадная дедупликация кластеров с `|corr| > 0.97` внутри списка отбора.
  - 3-й feature view **`mlp_wide`** (`max_cols = 140`, `dropout = 0.22`, `wd = 0.03`).

### 4. **Nowcaster v3**: Spatial Neighbor Graph + Фаза интервала + Диурнальная авторегрессия
- **Модуль:** `ag_nowcast.py`
- **4 неиспользованных резерва в текущем `ag_nowcast.py`:**
  1. **Spatial Neighbor Graph (без координат):** строго на прошлом (`h < cutoff_ts`) считаем корреляцию аномалий между группами `Corr(g_i, g_j)` и для каждой группы `g` добавляем взвешенное среднее её топ-3 коррелированных соседей на `h - 1` (`nbr_l1`, `nbr_anom`). Универсально работает для районов, филиалов, кластеров датчиков.
  2. **Внутрипериодная интерполяция (`phase_in_cadence`):** `phase = (t_event - floor(t_event, cadence)) / cadence` в `[0, 1]` и универсальная интерполяция `interp__c = (1 - phase) * lag1__c + phase * nc__c` + `staleness_frac` (в `10:03` состояние ближе к `09:00`, в `10:55` — к `nc__10:00`).
  3. **Взаимодействие аномалии с фазой суток:** `sin_h1 * lag1_anom`, `cos_h1 * lag1_anom` в матрице `Z` для GCV-Ridge (коэффициент затухания аномалии в 03:00 и в 08:30 разный!).
  4. **Отбор `top_cols` для LGBM-nowcaster + неопределённость:** гарантированно включать бинарные флаги с `|corr| >= 0.04` в `binary` LGBM-nowcaster (сейчас редкие штормовые/аварийные флаги часто выпадают из топ-6 по линейной корреляции) + оценка неопределённости `nc_abs_err` / квантильный разброс.

### 5. Контекстный Gated-Meta Ансамбль (`w(x)`) вместо скалярных весов
- **Модуль:** `ag_ensemble.py`
- **Проблема в `v11`:** `blend()` и `stack_blend()` используют фиксированные веса на всех строках, хотя `ResNet` сильно лучше деревьев на регулярных строках, а деревья (`cat_top`, `et`, `lgb`) стабильнее на скачках, сбоях сенсоров (`raw_nulls > 0`) и хвостах.
- **Решение:** честный вложенный OOF **Convex Context-Gated Blending**:
  - `y_hat(x) = sum_k w_k(x) * p_k(x)`, где `w(x) = softmax(a + B @ context_norm)` (`w_k >= 0, sum = 1`).
  - Компактный контекст (4–6 фич): `std` прогнозов семейств (эпистемическая неопределённость), `phase/minute`, `raw_nulls`, `nc_gbd`, `hist_count`.
  - Всего ~30 параметров + L2-регуляризация; в `publish()` честно конкурирует с `blend()` и `stack_blend()` и выбирается только при доказанном выигрыше на вложенном OOF.

### 6. 2-Stage Residual Boosting (**Neural → GBDT**)
- **Модуль:** `solution.py`
- **Идея:** когда нейросеть (`mlp`/`mlp_dual`) существенно бьёт одиночные деревья, обучать сильно регуляризованный CatBoost / LightGBM (`depth=4`, `lambda_l2=20`, `lr=0.03`) напрямую на OOF-остатках нейросети `r = y - oof_mlp` (строго out-of-fold, без утечки!). Деревья целиком фокусируются на острых локальных нелинейностях, которые сгладила нейросеть.

### 7. Динамический `seeders` + Pairwise Ranking Loss для PR-AUC / ROC-AUC
- **Модуль:** `ag_models.py`, `solution.py`
- **Динамический `seeders`:** вместо однократной фиксации списка `seeders` перед циклом, на каждой итерации выбирать семейство с максимальным `current_blend_weight / sqrt(n_seeds)` — математически минимизирует дисперсию ансамбля за 35-минутный бюджет.
- **Pairwise Ranking Loss в `_NumpyTabularResNet`:** на задачах с `average_precision` / `roc_auc` комбинировать `BCE + lambda * mean(log(1 + exp(-(z_pos - z_neg))))` внутри мини-батча — напрямую оптимизирует ранжирование верхушки (Fraud / Churn / Ad Engagement).

### 8. Бронебойный Private LB: Multi-Hop Snowflake SQL FK + JSONB / Array парсер
- **Модуль:** `ag_relational.py`, `ag_features.py`
- **Multi-Hop FK (до 3 хопов):** сейчас `pg_constraint` FK джойнятся только на 1 хоп от `train/test`. Итеративный обход FK-графа закроет схемы-снежинки (`orders → accounts → clients → regions`) с любыми нестандартными именами ключей.
- **JSONB / Postgres Arrays / Multi-delimiter теги:** авто-распаковка плоского JSON (до 8 ключей) + поддержка `{a,b}`, `;` и `|` в тег-матчере и `n_tags`.

### 9. Точная оптимизация экзотических метрик Private LB (`MAPE`, `LogLoss`, High-Card TE)
- **Модуль:** `ag_models.py`, `ag_ensemble.py`, `ag_features.py`
- **Точный `MAPE` через веса `1/|y|`:** на `metric == "mape"` (для ненулевых строк + `zero_mape_hurdle` на нули) передавать веса `w_i = 1 / max(|y_i|, q05)` в L1-модели (ResNet, LGBM, CatBoost) — математически тождественно прямой минимизации MAPE!
- **OOF Temperature Scaling для `LogLoss`:** 1-параметрическая калибровка `softmax(log(p) / T)` строго на вложенных OOF-фолдах за `0.05s` (`−0.005..−0.025 LogLoss` без переобучения).
- **Strictly-Causal Out-of-Fold Target Encoding** для high-cardinality категорий (`100..50k` уникальных) — открывает `ResNet`, `ET`, `Ridge` сигнал `user_id`/`merchant_id`/`sku_id`.

### 10. Умный AutoResearch: Residual-Correlation Feedback + Fast Pre-Screen LLM-фич
- **Модуль:** `ag_research.py`
- **Residual-Correlation Feedback:** за `0.05s` считать `corr(X_col, residual)` и `corr(X_col, |residual|)` и отдавать в промпт LLM топ-5 колонок с максимальной недооценкой/переоценкой — LLM будет предлагать точечные формулы под реальные провалы модели.
- **Fast Pre-Screen (`0.1s`):** перед полным 3-fold прогоном LightGBM отсеивать из сгенерированных LLM-колонок откровенный шум с нулевой корреляцией к остатку, чтобы шумные колонки не «топили» 2–3 сильные фичи из того же блока.
