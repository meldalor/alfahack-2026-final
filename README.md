# AutoML agent — финал, команда «клодики»

Основа: агент отборочного этапа `meldalor/alpha-hackathon-2026`.
Код одинаков для разных задач: схема PostgreSQL исследуется во время запуска,
таблицы соединяются по проверенным ключам, модели выбираются по собственной валидации.

## Запуск

Python 3.12. `python solution.py /path/to/task.md`.
Параметры подключения задаются окружением: `PGHOST`, `PGPORT`, `PGDATABASE`,
`PGUSER`, `PGPASSWORD`. Секреты не входят в репозиторий или ZIP.
LLM: `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL`.
Если PGDATABASE задан, данные загружаются из БД. Иначе поддерживаются CSV/Parquet.
В БД ожидаются train/test; справочники определяются по общей схеме ключей.
Шаблон sample_submission может лежать в БД либо в материалах рядом с task.md.

Доступ к PostgreSQL реализован через системную libpq без дополнительных Python-пакетов.
На сервере разработки она есть. Наличие libpq в контейнере проверки ещё не подтверждено.
`requirements.txt` пока перенесён без изменений из отбора: финальный утверждённый файл
и точный контракт передачи подключения/шаблона ещё нужно сверить с технической инструкцией.

## Изменения финала

- Плановый бюджет 6480 секунд, аварийный предел 7020 секунд при лимите 7200.
- Read-only PostgreSQL, таймаут запросов, автоматическая загрузка схемы.
- Соединения many-to-one, составные ключи, многошаговые связи, контроль числа строк.
- Почасовые измерения присоединяются по последнему времени не позже события,
  с давностью строго меньше обнаруженного шага измерений. Между районами данные не смешиваются.
- Для почти уникальных справочников исключаются конфликтующие ключи, включая составные.
- Текстовые идентификаторы PostgreSQL сохраняются без потери ведущих нулей.
- Для временного разбиения полная дата предпочтительнее дня года.
- Average Precision используется для ранней остановки LightGBM.
- ID распознаётся из условия и без шаблона; при наличии шаблона ответ упорядочивается по нему.
- Сохраняются AutoResearch, LLM-гипотезы, временная валидация и ансамбли отбора.
- Текстовые прогнозы-признаки в хронологических задачах обучаются только на прошлых периодах.
- Подвыборки для исследования сохраняют границы исходных временных фолдов.

## Проверка и сборка

`python tools/test_final.py` — проверки соединений, времени и формата ответа.
`python tools/selftest.py runs/selftest 120` — синтетические end-to-end задачи.
Для отдельной проверки: `--only=temporal_text`.
`python tools/llm_check.py /path/to/completed/run --cached` — LLM-цикл на извлечённых данных.
`python tools/probe_linear.py /path/to/completed/run` — исследование линейных моделей без замены ответа.
`python tools/make_zip.py dist/solution.zip` — модули .py и requirements.txt в корне ZIP.

## Материалы сервера разработки

Код: `/root/alfahack/final`, окружение: `/root/alfahack/.venv`.
Локальные публичные прогоны: `/root/alfahack/runs/task1`, `/root/alfahack/runs/task2`.
Эти каталоги не используются агентом при проверке на платформе.
Скрытые ответы не используются; оценки качества — только на обучающей временной валидации.
